## Websites inform

A website's job is to attract and convince: clear messaging, fast pages, search visibility and calls to action. Content management lets your team publish without developers.

## Web applications do work

A web application stores data and supports workflows: customer portals, admin dashboards, booking systems, CRMs. It needs authentication, permissions, databases and APIs.

## Comparison

| | Website | Web application |
| --- | --- | --- |
| Primary goal | Inform and convert | Complete tasks |
| Users | Anonymous visitors | Logged-in users |
| Key tech | CMS, SSR/SSG, SEO | Auth, database, APIs |
| Success metric | Traffic, enquiries | Task completion, efficiency |

## Connecting the two

The best results come when the website feeds the application — for example, website enquiries flowing straight into [lead management](/products/lead-management) with source tracking.

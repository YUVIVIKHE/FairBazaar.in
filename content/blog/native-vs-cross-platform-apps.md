## The three options

- **Native:** separate Kotlin (Android) and Swift (iOS) apps.
- **Flutter:** one Dart codebase, custom rendering.
- **React Native:** one JavaScript/TypeScript codebase, native components.

## Comparison

| | Native | Flutter | React Native |
| --- | --- | --- | --- |
| Codebases | Two | One | One |
| Time to market | Slowest | Fast | Fast |
| Device features | Full | Very good | Very good |
| Web code sharing | Low | Moderate | High (React) |
